## Technical Support Channels

For support issues related to the Platform Accelerator templates, pipelines, or clusters:

1. **Slack Channels**:
   - `#platform-engineering`: Architecture questions, golden template request help.
   - `#platform-alerts`: Direct integration channel for cluster alerts.
2. **Issue Tracker**:
   - Open tickets under the Platform GitHub project using the `support` tag.
3. **Escalation Path**:
   - **Severity 1 (Outage)**: Contact the On-Call Platform Engineer immediately via PagerDuty.
   - **Severity 2 (Pipeline Blocked)**: Response SLA within 4 hours during business days.
   - **Severity 3 (Feature request)**: Reviewed during sprint planning.
